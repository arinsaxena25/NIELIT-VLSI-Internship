# Analog and Digital VLSI Design Flow

This repository contains a small subset of both analog integrated circuit (IC) designs and digital logic implementations completed during my VLSI design flow internship from NIELIT NIT Calicut. All circuits, testbenches, and simulation setups have been simplified for clear understanding, practical reference, and modular design flow.

## Tools Used
* **Analog:** Cadence Virtuoso, Assura & LTspice
* **Digital:** Xilinx Vivado, Icarus Verilog (`iverilog`), GTKWave, & Synopsys VCS
